### 💧 [Water Quality Prediction — BE Final Project](https://github.com/sankalp5746/BE-Final-Project)

> An end-to-end **Machine Learning** system to predict water quality parameters (pH, dissolved oxygen, turbidity, etc.) from historical data — helping ensure access to safe water for drinking, agriculture, and industrial use.

**Highlights:**
- Collected, cleaned, and preprocessed real-world water quality datasets
- Engineered meaningful features and handled missing values & outliers
- Benchmarked **Linear Regression**, **Random Forest**, and **Gradient Boosting** models
- Deployed the best-performing model as a **Flask** web API on Vercel
- Evaluated with cross-validation, accuracy, precision, recall & F1-score

**Tech:** `Python` `Scikit-learn` `Flask` `Pandas` `Matplotlib` `Seaborn`
